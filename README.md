# YT Downloader para Windows — distribuição oficial

[Baixar a versão mais recente](https://github.com/Pr4Tes/youtube-downloader-releases/releases/latest)

Windows 10/11 x64. A edição pública 1.7.1 é leve: confirme Preparar agora no primeiro uso para obter yt-dlp, FFmpeg/FFprobe e Deno diretamente das fontes oficiais, com hashes fixados e ativação conjunta. É necessário internet nessa preparação. Componentes existentes, vídeos, histórico e configurações são preservados. Se adiar, use Diagnosticar e reparar. Esses quatro executáveis não estão no instalador. Licenças do runtime acompanham o pacote; fontes próprias privadas.

O atualizador confere manifesto assinado, compatibilidade, tamanho e SHA-256. Download e instalação dependem da ação/confirmação indicada no aplicativo. A primeira passagem de versões antigas sem atualizador é manual. Notas e arquivos oficiais estão nas releases.

Ensaios físicos entre aparelhos permanecem pendentes e foram dispensados pelo responsável nesta etapa. A verificação dos canais públicos por HTTPS e das assinaturas/pacotes é registrada separadamente.

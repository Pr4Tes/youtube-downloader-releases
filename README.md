# YT Downloader para Windows

Distribuição pública oficial de instaladores e metadados assinados. O código-fonte permanece privado.

Nenhuma versão estável foi publicada neste repositório ainda. Os artefatos 1.7.0 estão em preparação e dependem da aprovação do responsável.

As publicações aprovadas terão o instalador `YT-Downloader-Setup-<versão>.exe`, `version.json` e `version.json.sig`. O aplicativo confere a assinatura dos metadados, compatibilidade, tamanho e SHA-256 antes de oferecer a instalação. A instalação sempre depende de confirmação.
